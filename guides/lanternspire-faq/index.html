What is a spark?

A spark is a drop that lands within a few pixels of the lantern below. It keeps the full width, adds a bigger score, and raises the combo shown as Spark x.

Why did the lantern get thinner?

Only the overlapping part stays. The hanging edge is cut away. Later drops use that new width, so a sloppy stack gets harder fast.

Why does the swing speed up?

Speed rises with the height of the spire and with the number of sparks you have landed. It caps so the lantern is still readable.

How does the run end?

The run ends if the drop misses the lantern below, or if the remaining width is too thin to stack on. The end screen shows the reason.

Is the best score saved?

Yes. The best score is stored in this browser with local storage. Clearing site data resets it. There is no account.

Can I play on a phone?

Yes. Tap to drop. The page is a portrait canvas and works with touch. Keyboard still works on a desktop.

Is Lanternspire a copy of another stack game?

No. It uses a timing-stack idea that shows up in a lot of arcade games, with an original festival-lantern theme, scoring, and art made for Pixelsprout.
