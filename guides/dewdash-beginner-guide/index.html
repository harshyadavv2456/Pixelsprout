Dewdash - How to Play

Start a run

Open Dewdash and tap the canvas, or press Enter or Space. The sprout starts in the middle lane of a night garden path.

Read the three hazards

A brown rock fills the lane. Move left or right before you reach it. A low root is hopped. A green branch overhead is ducked. Hopping a branch or ducking a rock still counts as a hit.

Score dew and distance

Each pale orb is worth 25 points if you pass through it in that lane without being high in a hop. Distance adds the rest of the score. The path gets faster as the run goes on.

Restart

A crash ends the run and stores a new best if you beat it. Tap or press Enter to run again. The best score stays in this browser.
