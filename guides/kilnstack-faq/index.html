What is Kilnstack?

A Pixelsprout original arcade game. You time a swinging clay brick and stack it on a night kiln.

How do I score?

Each set that stays on the stack scores one. A Perfect scores more, and a streak of Perfects adds a combo on top.

What is a Perfect?

A set that lands almost on the center of the brick below. The new brick snaps flush, so you do not lose width.

Why did the brick get thinner?

Only the overlap is kept. A late or early set cuts clay off one side. The next brick is only as wide as what remains.

When does the run end?

When the overlap is too thin to hold. The kiln goes cold and you can start again from the title.

Does it get faster?

Yes. The swing widens and speeds up as the stack climbs, so later sets need a tighter tap.

Does it save my score?

Your best score stays in this browser. Clearing the site data clears the score.

Is it free, and does it work on a phone?

Yes. Nothing to install. Tap the game to set a brick. It also works with a keyboard.
