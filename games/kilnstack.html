About Kilnstack

Kilnstack is a Pixelsprout original. A clay brick swings over a night kiln. Set it when it lines up with the brick below. The overlap stays, the rest crumbles into the ash. Perfect sets snap flush and raise a combo. The swing gets wider and faster as the stack climbs. Miss the lip and the kiln goes cold.

How to play

  1. Tap the game, or press Space or Enter, to set the swinging brick.
  2. Only the part that overlaps the brick below stays on the stack.
  3. A near-center set is a Perfect. Perfects snap flush and add a combo bonus.
  4. The swing speeds up as the tower grows. If the overlap is too thin, the stack falls and the run ends.
