About Two Colored Ballz

In this fast-paced, action-packed game, you control a player ball that changes color between black and white. The goal of the game is to match the color of the player ball with the color of the small balls coming from two directions. If you match the colors, you score points. The game gets faster and more challenging as you progress, so youll need to be quick and nimble to keep up. Features: Fast-paced action: The game is fast-paced and challenging, requiring quick reflexes and good hand-eye coordination. Simple controls: The game is easy to learn and play.
